# Workshop: Claude Agents for Efficient Work — Курсова работа

## Тема: FitZone — фитнес клуб без онлайн присъствие

**Студент:** Божидар | **Username:** badmind

---

## Проблем

Фитнес клуб FitZone работи 7 години в кв. Люлин, София, но няма никакво онлайн присъствие. Клиентите го намират само по препоръка от квартала. Целта е проста уебстраница с услуги, цени, програма и форма за запис за пробна тренировка.

## Решение

Едностранична HTML уебстраница (landing page) с:
- **Hero секция** — ключово послание + статистики
- **Услуги** — 4 карти (тежести, кардио, групови, личен треньор)
- **Цени** — 4 абонаментни плана (10 лв. до 599 лв./год.)
- **Седмична програма** — таблица с 6 групови тренировки
- **Форма за запис** — безплатна пробна тренировка
- **Локация** — адрес, работно време, транспорт
